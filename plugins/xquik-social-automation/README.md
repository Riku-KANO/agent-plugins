# xquik-social-automation

Claude Code skill for using Xquik safely in X data workflows.

## What It Covers

- Tweet and user lookup planning.
- Search, media, thread, article, and engagement workflows.
- Bulk extraction estimates and approval flow.
- Monitor and webhook setup boundaries.
- MCP setup and operation selection.
- Confirmation-gated publishing and account actions.

## Install

```text
/plugin marketplace add Riku-KANO/agent-plugins
/plugin install xquik-social-automation@personal-agents
```

Set `XQUIK_API_KEY` in the local agent environment before making API calls.
